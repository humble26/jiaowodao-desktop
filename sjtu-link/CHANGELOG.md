# 更新日志（Changelog）

## v2.5.0（2026-08-22）— 稳定性与健壮性修复

- **修复：数据更新功能在极端场景卡死**——远端文件列表为空时不会触发任何脚本回调，
  更新入口的 `checking` 会永久置真；现提前终止并安全兜底
- **修复：缓存保存失败无感知**——localStorage 配额写满时，新数据仅驻留内存，
  现会显式提示「未能持久化缓存」，避免"看似已更新实则未生效"
- **修复：收藏侧栏无效嵌套**——原先在 `<a>` 中内嵌 `<button>`（非法 HTML），
  现改为容器 `div` +「直达链接/标题」与「删除按钮」两个兄弟节点，并保留整行直达行为
- **修复：关闭「常用优先」后恢复顺序不稳定**——比较器对未进快照的自定义链接
  违反传递性，现补名称 tiebreaker，顺序固定可预期
- **修复：「清空本地数据」遗漏项**——现同时清理自定义日程、免责声明「不再显示」
  勾选与收藏侧栏展开状态
- **修复：免责声明正文 XSS 隐患**——正文渲染改为「整体转义 + 白名单放行
  （`<br>`/`<b>`）」，保留排版的同时杜绝文案注入
- **修复：倒计时天数计算偏差**——改以 UTC 归一化计算整日差，避免时区/夏令时
  导致的 ±1 天误差
- **修复：二维码生成污染库全局状态**——临时切换 UTF-8 编码后即恢复原函数，
  不再影响其它调用方

## v2.4.4（2026-08-15）— 缓存机制重构

- **修复：页头按钮边框点击不生效**（免责声明等）——根因是 WebView2 缓存了旧版
  JS；机制缺陷在于缓存失效只监控 `app.html` 一个文件
- **缓存失效机制重构（双层保障）**：
  - 启动器监控**全部前端文件**（html/js/css）的最新修改时间，任一文件更新即清缓存
  - 仅当缓存删除**成功**后才记录版本标记；删除失败（WebView2 进程残留占用）不写标记，
    下次启动自动重试，旧缓存最终必然被清除
  - `app.html` 中全部 14 个 css/js 资源引用带 `?v=<版本号>`，版本更新后资源 URL
    变化，浏览器层面不可能命中旧缓存（`tools/sync_assets.py` 自动维护）
  - Edge 免安装版的 URL 版本参数同步升级为按全部前端文件计算

## v2.3.0（2026-08-15）— 缺陷修复与体验优化

### 缺陷修复

- **二维码弹窗点击无反应**：元素选择器不匹配（`.qr-close-btn` 应为 `#qr-close-btn`）导致
  弹窗构建中断——已修复，并经浏览器级 E2E 测试页（`tools/qr-modal-e2e.html`）验证
- **二维码图无法生成**：内置二维码库 UMD 缺少浏览器全局分支，`window.qrcode` 未定义——
  已补全局挂载（中文内容经 OpenCV 真实解码验证）
- **开启常用排序后卡片未即时重排**：`items` 已重排但网格未重绘——补 `renderGrid()`
- **清空搜索框后联想下拉残留旧建议**：程序化清空不触发 input 事件——清空按钮联动关闭下拉
- **切换语言后倒计时横幅、收藏侧边栏文案未同步**：两模块监听语言切换并重渲染

### 功能增强

- 二维码弹窗新增「**复制链接**」「**保存图片**」按钮（保存为 `jiaowodao-qr.png`）

### 性能与隐私

- 搜索打分引入逐条目索引缓存，逐键联想提速约 7 倍（实测 0.14ms/查询）
- 建议下拉增加最大高度与内部滚动，小窗口不再溢出、键盘导航滚动定位正确
- 「清空本地数据」范围扩展至收藏、自定义链接与使用统计
