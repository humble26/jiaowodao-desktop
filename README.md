# 交我导 · 上海交通大学导航（桌面版）

> **当前版本：v2.5.1**（2026-09-06）｜ 完整更新日志见 [CHANGELOG.md](CHANGELOG.md)

上海交通大学常用网站 / 公众号 / 社团导航的桌面应用，UI 仿照网页版导航站
[交我导 sjtu-links.pages.dev](https://sjtu-links.pages.dev/) 的风格制作：
SJTU 红金配色、搜索框、类型页签、分类筛选、卡片式直达链接、深色模式、
中英文切换，以及一只可以拖拽互动的小宠物「导导」。

## 功能一览

- **基础导航**：303 条内置数据（网站 / 公众号 / 社团），离线可用
- **搜索增强**：热门直达预选栏、输入联想、拼音/首字母/英文缩写搜索、搜索历史、网址直达、`Ctrl+K` 快捷键
- **数据在线更新**：启动自动同步网页版数据、页头手动更新、本地缓存、更新日志
- **个人化**：收藏侧边栏、自定义链接、使用统计与常用排序、日程倒计时（考试周/假期）
- **分享**：右键卡片生成二维码（含名称与链接文字、可自选保存位置、复制链接）
- **免责声明**：进入弹出（中英切换）、页头常驻入口
- **设置面板**：字体大小、宠物开关、清空本地数据、更新日志、关于
- **三种运行方式**：单文件 exe（免 Python）/ Edge 应用模式（免安装）/ Python 版（pywebview）

## 快速开始

**方式一：一键安装（推荐）**

1. 下载 `交我导-桌面版安装包.zip` 并解压
2. 双击 `安装交我导.cmd`（或运行 `install-jiaowodao.ps1`）
3. 选择安装位置 → 自动创建桌面与开始菜单快捷方式

**方式二：直接运行**

- 解压后双击 `sjtu-link\Jiaowodao.exe`（正常版，免 Python，需 WebView2 或 Edge）
- 或双击 `sjtu-link\launcher-edge.vbs`（Edge 应用模式，零依赖）

详细安装指南见 `安装指南.md`（含纯文本版 `安装指南.txt`）。

## 系统要求

- Windows 10 / 11（推荐）；正常版需 WebView2 运行时或 Edge，免安装版需 Edge，Python 版需 Python 3.10+
- 首次使用「在线数据更新」需联网，离线不影响基本使用

## 项目结构

```
├── 交我导-桌面版安装包.zip   # 一键安装包（脚本 + 指南 + 应用本体）
├── install-jiaowodao.ps1    # 安装脚本（自选位置/三模式/快捷方式/卸载）
├── 安装交我导.cmd           # 双击安装入口
├── 安装指南.md / .txt       # 安装指南
├── CHANGELOG.md             # 版本更新日志
└── sjtu-link/               # 应用本体（源码/数据/测试/单文件 exe）
    ├── app.html             # 应用主体（界面与逻辑）
    ├── *.js / *.css         # 功能模块（搜索增强/在线更新/免责声明/收藏/二维码等）
    ├── Jiaowodao.exe        # 正常版单文件（PyInstaller 打包）
    ├── data/                # 内置数据（含拼音字段与映射表）
    └── tools/               # 数据维护与自动化测试
```

## 维护与开发

- **更新数据**：`python tools/enrich_data.py`（重新生成拼音字段）
- **发版流程**：改 `settings.js` 版本号 → `python tools/sync_assets.py`（资源版本参数）→ 跑全部测试 → 打包 zip
- **测试**：`tools/` 下共 10+ 套自动化测试（搜索/更新/免责声明/设置/收藏/倒计时/二维码解码/缓存机制/真实环境点击）
