一、三种版本说明
============================================================
本指南与安装脚本（install-jiaowodao.ps1、安装交我导.cmd）位于
同一目录，应用本体在旁边的 sjtu-link 文件夹中。请将「脚本 +
sjtu-link 文件夹」整体复制到目标电脑。

【正常版】（推荐）
  运行文件 : Jiaowodao.exe
  依赖     : 无需 Python；需要 WebView2 运行时或 Edge（Win10/11 一般自带）
  特点     : 单文件，双击即用，独立窗口；首次启动需自解压数秒

【免安装版】
  运行文件 : launcher-edge.vbs
  依赖     : 仅需 Microsoft Edge（Win10/11 自带）
  特点     : 零依赖最省心，Edge 应用模式窗口；不写系统注册表

【Python 版】
  运行文件 : launcher.py
  依赖     : Python 3.10+ 与 pywebview
  特点     : 面向开发者/有 Python 环境的用户，源码可自行修改

说明：三种版本使用完全相同的界面与数据（搜索增强、在线数据更新、
免责声明等），仅运行外壳不同。

二、系统要求
============================================================
  操作系统   : Windows 7 SP1 / 8 / 8.1 / 10 / 11（推荐 Win10/11 64 位）
  PowerShell : 3.0+（Win7 SP1 及以上系统自带 Windows PowerShell 5.1，
               无需安装）
  正常版     : WebView2 运行时（Win10/11 通常已内置；缺失时可从微软官网
               developer.microsoft.com/microsoft-edge/webview2/ 下载），
               或 Microsoft Edge
  免安装版   : Microsoft Edge（Win10/11 自带）
  Python 版  : Python 3.10+（python.org/downloads），并执行
               pip install pywebview
  网络       : 首次使用「在线数据更新」功能需要联网（离线不影响基本使用）

三、安装方式 A：一键安装脚本（推荐）
============================================================
A1. 准备
    把 install-jiaowodao.ps1、安装交我导.cmd 与 sjtu-link 文件夹放在
    同一个目录下，整个复制到目标电脑（U 盘 / 局域网 / 网盘均可）。

A2. 启动安装
    方法 1（最简单）：双击「安装交我导.cmd」。
    方法 2（命令行）：在该目录打开 PowerShell（或 cmd），执行：
        powershell -ExecutionPolicy Bypass -File .\install-jiaowodao.ps1

A3. 安装流程（交互式）
    1) 环境检测：脚本自动检测 WebView2 / Edge / Python，并打印结果。
    2) 模式选择：默认 auto —— 按「正常版 > 免安装版 > Python 版」
       优先级自动挑选当前机器可用的模式；也可以手动指定（见 A5）。
    3) 选择安装位置：弹出文件夹选择框（或直接输入路径回车），
       默认 %LOCALAPPDATA%\Programs\Jiaowodao（无需管理员权限）。
    4) 确认覆盖：目标目录已存在时会询问是否覆盖；检测到应用正在
       运行时会提醒先关闭。
    5) 复制与自检：复制全部文件后逐项校验（app.html、exe/vbs/
       launcher.py、数据文件等）。
    6) 快捷方式：桌面创建「交我导」（免安装版为「交我导（免安装）」）；
       开始菜单创建「交我导」目录，内含应用与「卸载交我导」入口。
    7) 立即启动：询问是否马上启动应用。

A4. 静默安装（自动化 / 批处理场景）
    示例 1：安装到默认位置，免询问，装完不启动
        powershell -ExecutionPolicy Bypass -File .\install-jiaowodao.ps1 -Silent
    示例 2：指定位置 + 指定模式 + 装完即启动
        powershell -ExecutionPolicy Bypass -File .\install-jiaowodao.ps1 -Silent -InstallDir "D:\Apps\Jiaowodao" -Mode exe -Launch

A5. 参数说明
    -InstallDir <路径>           安装位置（默认 %LOCALAPPDATA%\Programs\Jiaowodao）
    -Mode <auto|exe|edge|python> 安装模式，默认 auto 自动检测
    -Source <路径>               应用源目录（默认脚本同级的 sjtu-link）
    -Silent                      静默模式：全部使用默认值/参数值，不弹窗不询问
    -Launch                      安装完成后立即启动应用
    -NoDesktopShortcut           不创建桌面快捷方式
    -NoStartMenuShortcut         不创建开始菜单快捷方式
    -Uninstall                   卸载模式（配合 -InstallDir 指定要卸载的安装目录）

四、安装方式 B：正常版（手动）
============================================================
1. 将 sjtu-link 文件夹复制到目标位置，例如 D:\Apps\sjtu-link。
2. 确认系统有 WebView2 运行时或 Edge（Win10/11 一般满足）。
3. 双击 sjtu-link\Jiaowodao.exe 即可运行。
4. 需要快捷方式时，可在 sjtu-link 目录内运行旧版辅助脚本：
        powershell -ExecutionPolicy Bypass -File .\sjtu-link\install.ps1
   （该脚本会在桌面创建指向 exe 的「交我导」快捷方式；推荐改用
     方式 A 获得完整功能。）

============================================================
五、安装方式 C：免安装版（手动）
============================================================
1. 将 sjtu-link 文件夹复制到目标位置。
2. 双击 sjtu-link\launcher-edge.vbs 即可运行（Edge 应用模式窗口）。
   - 若双击无反应，右键该文件 -> 打开方式 -> 选择
     「Microsoft(R) Windows Based Script Host」。
3. 需要快捷方式：
        powershell -ExecutionPolicy Bypass -File .\sjtu-link\install-edge.ps1
   （在桌面创建「交我导（免安装）」快捷方式。）

============================================================
六、安装方式 D：Python 版（手动）
============================================================
1. 安装 Python 3.10+（python.org/downloads，安装时勾选
   Add python.exe to PATH）。
2. 安装依赖：
        pip install pywebview
3. 将 sjtu-link 文件夹复制到目标位置，运行：
        pythonw .\sjtu-link\launcher.py
4. 需要快捷方式：运行 .\sjtu-link\install.ps1（自动优先 exe；
   无 exe 时使用 pythonw）。
5. 可选：把启动器打包为单文件 exe（免 Python 分发）：
        pip install pyinstaller
        python -m PyInstaller --noconsole --onefile --name Jiaowodao .\sjtu-link\launcher.py
        copy .\dist\Jiaowodao.exe .\sjtu-link\Jiaowodao.exe

============================================================
七、卸载
============================================================
方法 1：开始菜单 -> 「交我导」->「卸载交我导」，按提示操作。
方法 2（命令行）：
        powershell -ExecutionPolicy Bypass -File .\install-jiaowodao.ps1 -Uninstall -InstallDir "D:\Apps\Jiaowodao"

卸载会删除桌面/开始菜单快捷方式，并询问是否删除安装目录。
用户数据（搜索历史、主题、数据缓存）位于 %LOCALAPPDATA%\pywebview，
如需彻底清除请一并删除。

八、常见问题
============================================================
【问题】双击 exe 后无反应 / 一闪而过
【解决】首次启动需自解压数秒，请稍等；仍然失败请改用免安装版。

【问题】杀毒软件拦截 / 误报
【解决】PyInstaller 打包的程序可能被误报，请将其加入信任列表
       （本应用不联网上传任何数据）。

【问题】提示找不到 WebView2
【解决】下载安装 WebView2 运行时（见第二章链接），或改用免安装版。

【问题】数据更新提示失败
【解决】检查网络连接；离线时不影响本地数据与搜索。

【问题】想换安装位置
【解决】重新运行安装脚本并选择新位置，然后卸载旧位置。

【问题】应用正在运行无法覆盖安装
【解决】先退出应用再运行安装脚本。

【问题】修改侵权联系邮箱 / 版本信息
【解决】编辑 sjtu-link\app.html 中的 g1507285154@163.com 等文字后
       重新复制即可。
